\chapter{Tempos das implementações de núcleo compilado}
\label{ap:compilados}

Este apêndice reúne as tabelas de tempo das implementações de núcleo compilado
(C/C++), que no Capítulo~\ref{cap:resultados} servem apenas de referência.
Conforme os critérios da Seção~\ref{sec:criterios}, esses tempos não são
comparados diretamente com os das implementações interpretadas; a comparação
entre linguagens é feita somente pelo expoente empírico de crescimento
(Seção~\ref{sec:crescimento}). As instâncias são as mesmas das tabelas
correspondentes do Capítulo~\ref{cap:resultados}.
